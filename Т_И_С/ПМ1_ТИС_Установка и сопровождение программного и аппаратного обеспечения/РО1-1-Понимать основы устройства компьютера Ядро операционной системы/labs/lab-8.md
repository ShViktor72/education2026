# Лабораторная работа

## Цель работы

Научиться наблюдать процессы, потоки, службы и нагрузку операционной системы в Linux и Windows.

## Необходимое ПО

- Linux ВМ
- Windows или Windows Server ВМ
- Терминал Linux
- PowerShell или стандартные средства Windows

## Задание

Найти процессы в Linux и Windows, определить PID, посмотреть нагрузку, завершить учебный процесс и проверить состояние служб.

## Пошаговый порядок выполнения

1. В Linux запустите несколько безопасных процессов, например `sleep 300`.
2. Найдите их через `ps aux`, `pgrep` и `top`.
3. Запишите PID найденного процесса.
4. Завершите учебный процесс командой `kill`.
5. Посмотрите дерево процессов через `pstree`, если команда доступна.
6. Проверьте состояние одной службы через `systemctl status`.
7. Посмотрите список служб через `systemctl list-units --type=service`.
8. В Windows откройте Task Manager.
9. Перейдите на вкладку Details и найдите PID процесса.
10. Запустите безопасное приложение и завершите его через Task Manager.
11. Откройте Services и найдите несколько работающих служб.
12. Откройте Resource Monitor и посмотрите CPU, memory, disk и network.
13. Сравните инструменты Linux и Windows.

## Ожидаемый результат

В отчете должны быть:

- PID учебного процесса в Linux;
- команда завершения процесса;
- пример состояния службы Linux;
- PID процесса в Windows;
- пример службы Windows;
- скриншот или описание Resource Monitor;
- таблица сравнения Linux и Windows по инструментам мониторинга;
- вывод о признаках зависшего или ресурсоемкого процесса.
