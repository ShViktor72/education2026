# Лабораторная работа

## Работа в Bash, навигация и редактирование файлов

## Цель работы

Научиться выполнять базовые действия в терминале Linux, перемещаться по каталогам, читать справку и редактировать текстовые файлы.

## Необходимое ПО

- Linux Server
- Terminal

## Задание

Выполнить практическую работу по теме лекции и оформить отчет с командами, результатами проверки и выводом.

## Пошаговый порядок выполнения

1. Определить текущий каталог командой pwd.
2. Перейти в домашний каталог через cd, cd ~ и cd без аргументов.
3. Перейти на уровень выше через cd ..
4. Вернуться в предыдущий каталог через cd -.
5. Посмотреть содержимое каталогов через ls, ls -l, ls -a.
6. Открыть справку man ls и ls --help.
7. Создать текстовый файл через echo.
8. Просмотреть файл через cat, less, head, tail.
9. Отредактировать файл в nano.
10. Открыть файл в vi/vim, добавить строку, сохранить и выйти.
11. Описать использованные команды и параметры.

## Ожидаемый результат

- Созданные и отредактированные текстовые файлы.
- Список использованных команд навигации.
- Краткое сравнение nano и vim.
- Вывод о безопасной работе в терминале.

## Контрольные вопросы

1. Как перейти в домашний каталог?
2. Что означает .. в пути?
3. Чем ls -l отличается от ls -a?
4. Где посмотреть справку по команде?
5. Почему перед rm полезно выполнить pwd?
