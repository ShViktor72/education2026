# Лабораторная работа

## Управление службами и анализ журналов

## Цель работы

Научиться управлять службами Linux через systemctl, включать автозагрузку и анализировать журналы через journalctl.

## Необходимое ПО

- Linux Server
- Terminal

## Задание

Выполнить практическую работу по теме лекции и оформить отчет с командами, результатами проверки и выводом.

## Пошаговый порядок выполнения

1. Проверить состояние службы SSH.
2. Посмотреть список активных служб.
3. Остановить и запустить учебную службу или SSH по указанию преподавателя.
4. Выполнить restart службы и описать результат.
5. Выполнить reload службы, если служба поддерживает reload.
6. Сравнить restart и reload.
7. Включить службу в автозагрузку и проверить is-enabled.
8. Посмотреть журналы службы через journalctl -u.
9. Найти последние сообщения загрузки через journalctl -b.
10. Изменить безопасный параметр конфигурации службы, вернуть его обратно и проверить журнал.

## Ожидаемый результат

- Отчет с командами systemctl.
- Вывод journalctl по службе.
- Объяснение состояний active, inactive, failed.
- Сравнение restart и reload.

3. Что делает systemctl enable?
4. Когда используют journalctl -u?
5. Почему перед правкой конфигурации нужна копия?
