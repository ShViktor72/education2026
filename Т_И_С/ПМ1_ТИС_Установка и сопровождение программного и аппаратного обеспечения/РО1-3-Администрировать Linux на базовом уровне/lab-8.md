# Лабораторная работа

## Установка, обновление и удаление пакетов

## Цель работы

Научиться устанавливать, проверять, обновлять и удалять пакеты в Linux.

## Необходимое ПО

- Linux Server
- Terminal
- Интернет-доступ или локальный репозиторий

## Задание

Выполнить практическую работу по теме лекции и оформить отчет с командами, результатами проверки и выводом.

## Пошаговый порядок выполнения

1. Обновить индекс пакетов через apt update.
2. Найти пакет диагностической утилиты через apt search.
3. Установить выбранный пакет через apt install.
4. Проверить путь к установленной программе и ее версию.
5. Посмотреть информацию о пакете через apt show.
6. Удалить пакет через apt remove.
7. Установить локальный .deb-пакет через dpkg при наличии учебного файла.
8. Установить пакет через snap при наличии snap в системе.
9. Сравнить apt, dpkg и snap по назначению.
10. Описать риски подключения сторонних репозиториев.

## Ожидаемый результат

- Отчет по установке и удалению пакетов.
- Проверка версии установленной программы.
- Сравнительная таблица apt, dpkg, dnf/yum, snap.
- Вывод о безопасной установке ПО.
