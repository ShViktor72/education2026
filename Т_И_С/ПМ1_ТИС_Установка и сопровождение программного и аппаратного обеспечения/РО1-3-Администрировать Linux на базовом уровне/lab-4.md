# Лабораторная работа

## Создание пользователей, групп и настройка sudo

## Цель работы

Научиться создавать пользователей и группы, управлять членством в группах и настраивать базовые административные права.

## Необходимое ПО

- Linux Server
- Terminal

## Задание

Выполнить практическую работу по теме лекции и оформить отчет с командами, результатами проверки и выводом.

## Пошаговый порядок выполнения

1. Создать пользователя через useradd или adduser.
2. Задать пользователю пароль.
3. Создать группу developer.
4. Добавить пользователя в дополнительную группу.
5. Проверить UID, GID и группы пользователя.
6. Изучить записи в /etc/passwd, /etc/shadow, /etc/group.
7. Создать второго пользователя и изменить его основную группу.
8. Дать одному пользователю право использовать sudo.
9. Проверить выполнение административной команды через sudo.
10. Описать, почему NOPASSWD нужно применять осторожно.

## Ожидаемый результат

- Созданные пользователи и группы.
- Проверка членства в группах.
- Пример настройки sudo.
- Вывод по базовой безопасности учетных записей.

## Контрольные вопросы

1. Какая команда показывает группы пользователя?
2. Что делает usermod -aG?
3. Почему нельзя постоянно работать под root?
4. Для чего используется sudo?
5. Как безопасно редактировать sudoers?
