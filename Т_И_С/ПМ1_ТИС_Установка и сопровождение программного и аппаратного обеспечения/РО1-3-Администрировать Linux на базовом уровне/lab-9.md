# Лабораторная работа

## Настройка сети, SSH-доступа и базового firewall

## Цель работы

Научиться проверять сетевые параметры Linux, подключаться по SSH, настраивать SSH-ключи и применять базовые правила firewall.

## Необходимое ПО

- Linux Server
- Terminal
- SSH-клиент
- UFW

## Задание

Выполнить практическую работу по теме лекции и оформить отчет с командами, результатами проверки и выводом.

## Пошаговый порядок выполнения

1. Проверить IP-адреса интерфейсов через ip addr.
2. Проверить состояние интерфейсов через ip link.
3. Проверить таблицу маршрутизации через ip route.
4. Проверить DNS-настройки и разрешение имени.
5. Изменить hostname учебной ВМ и проверить результат.
6. Подключиться к Linux-серверу по SSH с другой ВМ или с хостовой системы.
7. Создать SSH-ключ и настроить вход по ключу.
8. Проверить настройки sshd_config, не отключая доступ без резервного способа входа.
9. Настроить ufw: разрешить SSH и HTTP.
10. Ограничить SSH-доступ только из указанной учебной сети.
11. Проверить доступность разрешенных и запрещенных подключений.
12. Описать, почему firewall нужно настраивать аккуратно при удаленном доступе.

## Ожидаемый результат

- Проверенные сетевые параметры Linux.
- Рабочее SSH-подключение.
- Настроенный вход по SSH-ключу.
- Базовые правила ufw.
- Отчет с результатами подключения и проверки firewall.

3. Как работает SSH-ключ?
4. Почему нужно осторожно менять sshd_config?
5. Как не потерять доступ при включении firewall?
