# Лабораторная работа

## Управление файлами, каталогами и ссылками

## Цель работы

Научиться выполнять базовые операции с файлами и каталогами, создавать жесткие и символические ссылки и понимать их поведение.

## Необходимое ПО

- Linux Server
- Terminal

## Задание

Выполнить практическую работу по теме лекции и оформить отчет с командами, результатами проверки и выводом.

## Пошаговый порядок выполнения

1. Создать рабочий каталог для лабораторной работы.
2. Создать несколько файлов через touch и echo.
3. Создать вложенную структуру каталогов.
4. Скопировать и переместить файлы между каталогами.
5. Найти файл командой find.
6. Создать файл file1 и наполнить его содержимым.
7. Создать копию file2, символическую ссылку file3 и жесткую ссылку file4.
8. Посмотреть inode файлов через ls -i или stat.
9. Удалить исходный file1 и проверить file2, file3, file4.
10. Сделать вывод о различии копии, hard link и symlink.

## Ожидаемый результат

- Созданная структура каталогов.
- Набор файлов, копий и ссылок.
- Таблица inode.
- Вывод о поведении hard link и symlink после удаления исходного файла.

## Контрольные вопросы

1. Что хранится в inode?
2. Почему hard link продолжает работать после удаления исходного имени?
3. Почему symlink может стать битым?
4. Чем cp отличается от ln?
5. Как безопасно проверить каталог перед удалением?
