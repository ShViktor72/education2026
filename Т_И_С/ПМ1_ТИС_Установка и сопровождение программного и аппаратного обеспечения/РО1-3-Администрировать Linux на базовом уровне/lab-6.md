# Лабораторная работа

## Процессы, перенаправление потоков и конвейеры

## Цель работы

Научиться просматривать и завершать процессы, перенаправлять стандартные потоки и строить простые конвейеры команд.

## Необходимое ПО

- Linux Server
- Terminal

## Задание

Выполнить практическую работу по теме лекции и оформить отчет с командами, результатами проверки и выводом.

## Пошаговый порядок выполнения

1. Запустить учебный процесс sleep 300.
2. Найти его PID через ps, pgrep или top.
3. Завершить процесс сигналом SIGTERM.
4. Запустить процесс повторно и завершить сигналом SIGKILL.
5. Создать файл с помощью echo.
6. Выполнить команду с ошибками и перенаправить stderr в отдельный файл.
7. Использовать cat, grep, sort, uniq в конвейере.
8. Получить список прав доступа через ls -l, cut, sort, uniq.
9. Сохранить результат pipeline в файл.
10. Описать различие stdout и stderr.

## Ожидаемый результат

- Команды управления процессами выполнены.
- Созданы файлы с перенаправленным выводом и ошибками.
- Собран рабочий pipeline.
- В отчете объяснены PID, сигнал, stdout и stderr.

## Контрольные вопросы

1. Как найти PID процесса?
2. Почему SIGKILL используют осторожно?
3. Что означает stderr?
4. Как добавить вывод в конец файла?
5. Как работает конвейер команд?
