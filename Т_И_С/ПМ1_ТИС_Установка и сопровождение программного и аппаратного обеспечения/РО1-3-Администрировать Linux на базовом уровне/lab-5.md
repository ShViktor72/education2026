# Лабораторная работа

## Настройка прав доступа по сценарию

## Цель работы

Научиться назначать владельцев, группы, права доступа и специальные биты для файлов и каталогов по практическому сценарию.

## Необходимое ПО

- Linux Server
- Terminal

## Задание

Выполнить практическую работу по теме лекции и оформить отчет с командами, результатами проверки и выводом.

## Пошаговый порядок выполнения

1. Создать группу developer и нескольких пользователей.
2. Создать каталог для совместной работы группы.
3. Назначить владельца и группу каталога.
4. Настроить права так, чтобы участники группы могли создавать и изменять файлы.
5. Настроить SGID для наследования группы в каталоге.
6. Создать подкаталог для обмена файлами.
7. Настроить sticky bit, чтобы удалять файлы могли только их владельцы.
8. Создать файлы с разными правами в числовом и символьном виде.
9. Проверить доступ от имени разных пользователей.
10. Описать типовые ошибки настройки прав.

## Ожидаемый результат

- Настроенная структура каталогов для совместной работы.
- Проверка доступа от имени разных пользователей.
- Примеры chmod и chown.
- Вывод о применении SGID и sticky bit.

## Контрольные вопросы

1. Какие права нужны группе для совместной папки?
2. Почему для каталога важно право x?
3. Что делает SGID на каталоге?
4. Когда нужен sticky bit?
5. Почему не стоит использовать chmod 777?
