# Лабораторная работа

## Первичная проверка Linux Server

## Цель работы

Научиться выполнять первичную проверку установленной Linux-системы после установки или получения сервера в работу.

## Необходимое ПО

- Linux Server
- Terminal
- SSH-клиент при наличии

## Задание

Выполнить практическую работу по теме лекции и оформить отчет с командами, результатами проверки и выводом.

## Пошаговый порядок выполнения

1. Войти в установленную Linux Server ВМ.
2. Определить текущего пользователя командой whoami.
3. Проверить домашний каталог и текущий путь.
4. Посмотреть версию дистрибутива через cat /etc/os-release.
5. Проверить версию ядра командой uname -a.
6. Проверить hostname командой hostnamectl.
7. Проверить время и часовой пояс.
8. Проверить RAM и swap командой free -h.
9. Проверить диски и файловые системы через lsblk и df -h.
10. Проверить IP-адрес через ip addr и gateway через ip route.
11. Составить первичный паспорт Linux-сервера.

## Ожидаемый результат

- Заполненный чек-лист первичной проверки.
- Таблица с версией ОС, ядром, hostname, RAM, дисками и IP-адресом.
- Вывод о готовности системы к дальнейшим лабораторным работам.

## Контрольные вопросы

1. Зачем проверять систему после установки?
2. Чем hostname полезен администратору?
3. Что показывает uname -a?
4. Почему нужно фиксировать свободное место на диске?
5. Какие признаки говорят, что сеть настроена базово корректно?
