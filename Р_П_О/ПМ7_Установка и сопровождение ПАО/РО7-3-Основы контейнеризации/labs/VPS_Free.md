# Бесплатные VPS и облачные виртуальные машины

**Проверено:** 8 ноября 2026 года  
**Назначение:** учебное развёртывание Docker Compose (Nginx → Express API → PostgreSQL 18) на Linux-сервере.

> **Важно:** «бесплатная виртуальная машина» не всегда означает «сервер с публичным IP и без каких-либо платежей». Сетевой трафик, диски, публичные IP-адреса и превышение лимитов могут оплачиваться отдельно. Тарифы и доступность ресурсов меняются. Перед регистрацией проверьте условия на официальном сайте.

## Краткое сравнение

| Провайдер | Бесплатный вариант VM | Срок | Ключевое ограничение |
|---|---|---|---|
| **Oracle Cloud Infrastructure (OCI)** | Always Free: Ampere A1 — до 1 500 OCPU-часов и 9 000 ГБ-часов RAM в месяц (пример: 2 OCPU и 12 ГБ RAM на весь месяц); также до 2 слабых AMD Micro VM | Без заранее установленного окончания | ARM64 у A1; нехватка доступных VM в регионе; простаивающие VM могут быть отозваны |
| **Google Cloud Compute Engine** | Free Tier: `e2-micro` в отдельных регионах США; до 30 ГБ стандартного постоянного диска | Без заранее установленного окончания | Публичный IPv4 VM обычно платный; мало ресурсов и ограничен исходящий трафик |
| **Amazon Web Services (AWS)** | Free account plan: $100 кредитов сразу и до $100 за выполнение действий | До 6 месяцев **или** исчерпания кредитов | Не постоянный бесплатный VPS; конкретные VM потребляют кредиты |
| **Microsoft Azure** | Free account: до 750 часов/мес. для подходящих B-серий VM (B1s, B2pts v2, B2ats v2) | 12 месяцев для новых клиентов | Размер VM, диск, IP и другие услуги нужно проверять отдельно |

## 1. Oracle Cloud — Always Free

**Регистрация:** https://www.oracle.com/cloud/free/  
**Лимиты и технические условия:** https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm  
**Условия Free Tier:** https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier.htm

- **Постоянно бесплатные ресурсы:** OCI Ampere A1 Flex (архитектура **ARM64**) — суммарно до **1 500 OCPU-часов** и **9 000 ГБ-часов памяти** в месяц. Для непрерывной работы в рамках месячного лимита Oracle приводит пример конфигурации **2 OCPU, 12 ГБ RAM**. Можно распределить квоту между допустимыми VM.
- Дополнительно доступны до **двух VM.Standard.E2.1.Micro (AMD)** с **1 ГБ RAM** каждая; применяются ограничения по доступности и дисковому пространству.
- **Диски:** общий бесплатный лимит block volume, включая загрузочные диски, — **200 ГБ** в домашнем регионе; создание VM расходует часть этого лимита.
- **Регистрация:** для большинства пользователей требуются номер телефона и банковская карта для подтверждения личности.
- **Риски:** при создании VM может появляться ошибка **Out of host capacity**; Oracle также предупреждает, что неиспользуемые («idle») Always Free VM могут быть отозваны.
- **Для лабораторной:** наиболее интересный вариант по объёму памяти; заранее проверить, поддерживают ли все выбранные Docker-образы платформу `linux/arm64`.

> Примечание: у Oracle в некоторых прайс-листах встречаются **3 000 OCPU-часов и 18 000 ГБ-часов** для *платных аккаунтов*. Это **не** лимит, который следует обещать обычному аккаунту **Always Free**. В этой памятке указана квота Always Free из соответствующей документации.

## 2. Google Cloud — Compute Engine Free Tier

**Программа:** https://cloud.google.com/free  
**Точные лимиты Free Tier:** https://docs.cloud.google.com/free/docs/free-cloud-features  
**Тарифы на публичные IP:** https://cloud.google.com/vpc/network-pricing

- **Постоянно бесплатная квота:** суммарно время работы **одной VM типа `e2-micro`** в месяц, только в регионах **`us-west1` (Орегон), `us-central1` (Айова), `us-east1` (Южная Каролина)**.
- **Диск:** до **30 ГБ-месяцев Standard Persistent Disk**.
- **Исходящий трафик:** до **1 ГБ/месяц** в рамках указанного Free Tier (применяются географические исключения).
- **Публичный IPv4:** не входит в бесплатные часы VM. Для обычной работающей VM официальная цена — **$0,005/час**, бесплатная квота публичного IP — **1 час в месяц**. При 720 часах использования расчёт: `(720 − 1) × $0,005 = $3,595` (~**$3,60**) **только за IP**, если применяется именно этот тариф; другие услуги не учтены.
- **Пробный период для новых аккаунтов:** отдельный **$300 кредит на 90 дней**. После окончания trial для сохранения работающих ресурсов нужно следовать условиям перехода на платёжный аккаунт.
- **Для лабораторной:** годится для знакомства с SSH и Docker, но для стека Nginx + API + PostgreSQL ресурсов `e2-micro` может быть мало; не следует считать общую стоимость с публичным IPv4 нулевой.

## 3. AWS — Free Tier / Free Account Plan

**Регистрация и тариф:** https://aws.amazon.com/free/  
**Официальные условия:** https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/free-tier.html  
**FAQ:** https://aws.amazon.com/free/free-tier-faqs/

- **Новые клиенты:** получают **$100 кредитов** при регистрации; ещё **до $100** можно заработать за выполнение определённых действий.
- **Free account plan:** действует **до 6 месяцев либо до расходования кредитов**, в зависимости от того, что наступит раньше.
- По условиям *Free account plan* платные списания не производятся без перехода на платный план; после завершения бесплатного периода ограничения на доступ к ресурсам меняются.
- **Важно:** это **не** бессрочная бесплатная EC2 VM и не фиксированный набор выделенных CPU/RAM на весь период. Фактическая продолжительность работы зависит от выбранной VM и расходования кредитов.
- **Для лабораторной:** хороший временный VPS для практики развёртывания, SSH, правил безопасности и мониторинга затрат.

## 4. Microsoft Azure — Free Account

**Регистрация:** https://azure.microsoft.com/free/  
**Перечень бесплатных сервисов:** https://azure.microsoft.com/en-us/pricing/purchase-options/azure-account  
**Как выбирать Free Services:** https://learn.microsoft.com/en-us/azure/cost-management-billing/manage/create-free-services

- **Новые клиенты:** доступ к некоторым бесплатным VM в течение **12 месяцев**; среди указанных типов — **B1s, B2pts v2 (ARM), B2ats v2 (AMD)**.
- **Лимит:** для подходящих типов предусмотрено до **750 часов в месяц** по условиям программы; проверяйте конкретные доступные типы и часовые квоты в учётной записи.
- **Пробный кредит:** **$200 на 30 дней** для подходящих новых аккаунтов.
- **Регистрация:** обычно требуются номер телефона и банковская карта для подтверждения личности.
- **Дополнительные расходы:** диски, публичный IP, трафик и ресурсы вне бесплатной квоты необходимо проверять отдельно. Выбор неподходящего типа VM может привести к оплате.
- **Для лабораторной:** подходит для временной демонстрации Linux, Docker Compose и SSH, если удаётся создать VM допустимого бесплатного типа.

## Рекомендация для итоговой лабораторной №12

**Если нужен настоящий VPS без заранее ограниченного периода:** сначала проверить **Oracle Cloud Always Free Ampere A1**. Учитывать ARM64, банковскую карту при регистрации, доступность VM и риск отзыва неиспользуемых инстансов.

**Если сервер нужен только на время обучения:** подойдут пробные предложения **AWS** или **Azure** при соблюдении условий бесплатной программы.

**Если важнее не зависеть от регистрации и платёжных данных студентов:** оставить обязательную часть лабораторной на **Debian в VirtualBox**, а публичный VPS использовать преподавателю для демонстрации.

### Практическая проверка перед запуском Docker-проекта

1. Проверить, доступна ли VM в выбранном регионе и входит ли её тип в бесплатную квоту.
2. Уточнить условия банковской карты, публичного IPv4, SSD/блочного диска и исходящего трафика.
3. На VM проверить `uname -m`, чтобы правильно выбрать Docker-образы (`x86_64` или `aarch64`).
4. Настроить SSH-ключи и правила доступа; публиковать только Nginx, **не** PostgreSQL напрямую.
5. Проверить бюджет/лимиты в облачной консоли и удалить ненужные платные ресурсы после занятий.
6. Для PostgreSQL 18 монтировать именованный том в `/var/lib/postgresql`, а не в `/var/lib/postgresql/data`.
